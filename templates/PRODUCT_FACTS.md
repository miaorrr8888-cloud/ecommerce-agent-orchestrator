## BLOCKED_FIELDS

> 这些字段缺失，任何 Agent 不得猜测。总控只在结果页汇总，向老板一次性索要。

| 字段 | 为什么需要 | 影响哪个 Agent | 阻塞程度 |
|---|---|---|---|
| | | | 硬阻塞 / 可绕过 |

`BLOCKED_FIELDS.json` 格式：

```json
{
  "sku": "<sku>",
  "blocked": [
    {"field": "电池容量", "needed_by": ["COPY","IMAGE-C"], "severity": "hard", "reason": "口播需要续航时长"}
  ]
}
```
